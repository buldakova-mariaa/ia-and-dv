## 📌 О курсе

Курс «Интеллектуальный анализ и визуализация данных» посвящен проблеме «последней мили» аналитики — превращению результатов вычислений и предсказаний ML-моделей в визуальные интерфейсы, на которые человек может опереться при принятии решений. В рамках курса изучается методология работы с данными на всём их жизненном цикле — от разведочного анализа до построения интерактивных дашбордов и объяснимых моделей машинного обучения, используя современные инструменты бизнес-аналитики (Qlik Sense) и ML-инжиниринга (Python + Taipy).

Этот репозиторий содержит все материалы курса: презентации лекций, задания к практикам, контрольные вопросы, примеры кода, шаблоны для проектов и полезные ссылки.
