## Чек-лист установки ПО

**Общее для всех команд:** ноутбук с правами администратора; доступ к сети Интернет. Если устновка ПО не выполняется — сообщение преподавателю **до 12 сентября 2026 г.** (занятия 1.5).

### Вариант А (по умолчанию) — Трек «BI-аналитика» (Qlik Sense Desktop)

| Требование | Значение |
|---|---|
| Процессор | 4+ ядра, x64 |
| ОЗУ | 8 ГБ |
| Диск | 5 ГБ для установки; SSD с запасом 20+ ГБ под приложения (.qvf), логи, временные файлы |
| ОС и платформа | Windows 10/11; Microsoft .NET Framework 4.8 или выше |

Шаги:
1) скачать дистрибутив и лицензионный ключ(ссылку получить у ассистента преподавателя); 
2) установить; 
3) активировать ключом; 
4) создать/открыть тестовое приложение (.qvf).
    
Флажки готовности:
- [ ] установлено; 
- [ ] запускается; 
- [ ] приложение `Интерфейсный тренажер Qlik Sense.qvf.qvf` открывается.

### Вариант Б — трек «ML-инжиниринг» (Python + Poetry + VS Code)

| Требование | Значение |
|---|---|
| ОЗУ | не менее 16 ГБ (инференс модели курса — до 12 ГБ) |
| Диск | SSD, 20+ ГБ свободно (окружение включает тяжёлые пакеты) |
| ОС | Windows, Mac, Linux |

Если привыкли кодить в других IDE или в блокноте, то пункт с VS Code пропускайте.

Шаги: 
1) установить **Python 3.9–3.13**; 
2) установить **Poetry 2.x**; 
3) установить **VS Code** + расширения **Python** и **Jupyter**; 
4) получить от преподавателя описание зависимостей проекта курса (файл`pyproject.toml`); 
5) выполнить `poetry install`; 
6) проверка: `poetry run python -V` и `poetry run python -c "import numpy, pandas, sklearn, joblib, shap; print('OK')"`.

Единая среда — это важно: версии `scikit-learn`/`numpy` должны совпадать с версиями обучения предобученной модели, иначе `.joblib` не загрузится корректно.

Флажки готовности: 
- [ ] Python 3.9–3.13; 
- [ ] Poetry; 
- [ ] VS Code + расширения; 
- [ ] `poetry install` без ошибок; 
- [ ] проверка импортов вернула «OK».

## Занятие 1.4 «Установочный практикум: рабочие места и треки»

**Модуль 1 · практика · 50 мин · поток 3 и 6 курсы (05.09.2026)**

### 1 Цели и результаты обучения
**Цель:** подготовить рабочие места команд к проектной работе и зафиксировать профильные треки.
**Результаты:** команда имеет проверенную среду (чек-лист по флажкам), зафиксированный трек, задание СРС к занятию 1.5. 

### 2 План занятия

| № | Этап | Содержание | Время |
|---|---|---|---|
| 1 | Орг. часть | Сверка составов команд | 5 мин |
| 2 | Проверка окружения | Проверка по чек-листу установки ПО (флажки готовности) | 20 мин |
| 3 | Фиксация треков | Заполнение формы | 15 мин |
| 4 | Итоги и СРС | Критерии готовности к 1.5; задание на самостоятельную работу | 10 мин |

### 3 Ход занятия
**Шаг 1 (5 мин).** Сверка команд (2–3 человека).

**Шаг 2 (20 мин).** Проверка окружения. BI: запуск Qlik Sense Desktop, открытие приложения `Интерфейсный тренажер Qlik Sense.qvf.qvf`. ML: `poetry install` выполнен в СРС — проверка версий и импортов, VS Code с расширениями Python/Jupyter. Устранение типовых отказов (права администратора, блокировка антивирусом, конфликты версий).

**Шаг 3 (15 мин).** Фиксация готовности работы по выбранным трекам.

**Шаг 4 (10 мин).** Итоги: критерии готовности к 1.5. СРС: изучить «Меню кейсов» и подготовить предварительный выбор направления проекта в сквозном кейсе; ознакомиться с рабочей программой дисциплины (РПД).

### 4 Форма фиксации треков

1. Номер команды
2. Номер группы
3. Состав (ФИО)
4. Трек (B_аналитика / ML-инжиниринг)

### 5 Критерии завершения занятия
Команда готова к 1.5, если: все флажки чек-листа проставлены; трек зафиксирован в Форме; СРС к 1.5 получена. Команда с неготовой средой — по согласованию переносит проверку на консультацию, к 1.5 обязана прийти с рабочим местом.
